# Yatri Mortgage Nepali Video Editor — Agent Rules

## Core directive
Build a **clean, information-dense explainer video** using Remotion (React video engine) that clones the Yatri mortgage reference's design language. The raw speaker footage gets annotated with kinetic captions, icon tiles, animated graphics (coin stacks, red arrows, green checks), and precise sound design. Output: transparent ProRes 4444 layers that stack in CapCut.

## Read-first resources
- `design-systems/yatri-mortgage-nepali.json` — the canonical design spec (colors, fonts, motion params, layout).
- `rawtrascript.txt` — the full Nepali/English transcript; fix "China Expenses" → "Living Expenses" on screen.
- `data/words.json` — Nepali-safe word-level timestamps (generated by stable-ts). Feed this to kinetic caption components.

## Motion rules
- **Springs only.** No CSS transitions, no linear fades. All motion uses `spring({damping: 12, stiffness: 200, mass: 1})` from `@remotion/animation-utils`.
- Word pops: `0→1.08→1` scale (overshoot 8%), ±4° random rotation, +40→0 Y offset, 3-frame stagger.
- Row slides: `translateY(60→0)` easeOutBack over 10 frames.
- Icon tiles: 64×64, `radius: 12`, `bg: #F2C230`, centered icon in `#1B2A4A`.
- Draw-on strokes: SVG `stroke-dashoffset` 1→0 over 8–10 frames, never animated as `<animate>` tags.

## Nepali text rules
- **Font:** Noto Sans Devanagari Bold (loaded via `@remotion/google-fonts`).
- **Split by word, not character.** Devanagari matras (vowel marks) must stay attached to their consonants — a Remotion Text node per word, not per character.
- **Never rasterize outside Chromium.** FFmpeg `drawtext` will break conjuncts like "त्यो" and "ह्रः". Remotion renders in Chromium, so shapes them correctly.
- **Fix ASR errors:** "China Expenses" → "Living Expenses", "Housing Australia Government" → "Housing Australia" / "Government" (as separate words for color logic).

## Color semantics (meaning-matched exactly like the reference)
- `#F2C230` (yellow) → **the subject noun** being defined (5% Scheme, Retained Savings, criteria, homebuyer).
- `#2E9E4F` (green) → **every money / percentage token** (5%, 10%, 6 months, deposit amount).
- `#E23B2E` (red) → **every restriction / negative token** ("पाउनुहुन्न", "defeats", "cannot", criteria changes).
- `#FFFFFF` (white) → **neutral / connector words** (all filler, conjunctions).
- `#1B2A4A` (navy) → **static panel labels** ("OLD: Bank Policy", "NEW: Gov Rule", etc.).

## Asset sourcing rules
- **ONLY use `search_assets()` MCP tool.** Never invent filenames. The tool is backed by LanceDB + CLAP/OpenCLIP embeddings.
  ```ts
  const coinPath = await invoke('search_assets', {query: 'gold coin 3D', type: 'emoji'});
  const popSfx = await invoke('search_assets', {query: 'soft UI pop', type: 'sfx', k: 1});
  ```
- If `search_assets()` returns `null`, **fail loudly** (don't use a fallback, don't guess a path). Raise an issue in the transcript.

## Export rules
- Render each composition as **ProRes 4444 `yuva444p10le` (true alpha)** or **PNG sequence**.
- **Verify alpha:** corner pixel must be `rgba(0,0,0,0)` (fully transparent), not black with opacity. After render:
  ```bash
  ffmpeg -i out/captions.mov -vf "crop=1:1:0:0" -frames:v 1 -f rawvideo -pix_fmt rgba - | xxd | head -1
  # Must show: 00000000
  ```
- Do NOT use WebM or MP4; CapCut has unreliable alpha on those.
- **FPS lock:** 30fps everywhere (raw clip, `words.json`, renders). A 24/30 drift will misalign captions by seconds.

## Verification gates (do NOT proceed until all pass)
- [ ] 18 Fluent 3D emoji PNGs exist, ≥512px, transparent.
- [ ] 20 Lucide SVGs load, recolor correctly to navy `#1B2A4A`.
- [ ] `Noto Sans Devanagari` renders "पाउनुहुन्न", "त्यो", "ह्रः" (conjuncts) correctly in Chromium.
- [ ] `data/words.json` has ≥95% word count match vs transcript, last word frame ≈ 86.9s (2610 frames @ 30fps).
- [ ] `matte/` PNG sequence count == raw frame count (do NOT proceed if matte is 24fps and raw is 30fps).
- [ ] 13 SFX files are **dry (no reverb)**, silence-trimmed, −16dB peak, 48kHz WAV.
- [ ] 1 music bed ≥90s, instrumental, no vocals, no lead melody.
- [ ] `assets/manifest.json` has zero null paths, every asset source/license recorded.
- [ ] `search_assets("soft UI pop", "sfx")` returns a path string; `search_assets("3D house on coins", "emoji")` returns a path string.

## Component rules
- **KineticWord.tsx** reads one word from `words.json` (start, end, text, colorTag). Renders spring pop with the right color (yellow/red/green/white per tag). Stagger 3 frames per word.
- **RealityList.tsx** renders a list of icon-tile rows (title, icon, label text). Each row slides up easeOutBack 10 frames, staggered. Icon is a 64×64 yellow tile with navy icon centered.
- **CoinStack.tsx** builds the reference's signature motif: 4× coin 3D emoji stacked, house on top, red down-arrow sweeping L→R. All via spring bounces.
- **Root.tsx** is one `<Composition>` per effect (Captions, Panel, Motifs, CTA). Each exports separately as alpha.

## Timeline accuracy
- Use frame-exact timings from the master table (§B in the brief). Tolerance: ±2 frames (66ms).
- If a word's timestamp from `words.json` doesn't match the design spec, **trust the design spec** (the reference is frame-locked); adjust the transcript cut if needed.

## Quality gates (before final export)
- Capture a frame at every caption change. Diff vs reference side-by-side. Fix font size, color, position, timing until identical.
- Run SFX mix: vocal peak -6…-3dB LUFS, music -22…-30dB, SFX -14…-18dB. Use side-chain ducking on music (keyed to voice).
- Verify no soft-alpha (all edges are hard; no blur on text).

## If stuck
- Check `design-systems/yatri-mortgage-nepali.json` first (it's the source of truth).
- Use `git log --oneline` to see prior component versions (if any).
- If a Devanagari glyph looks wrong, it's a Remotion/Chromium rendering issue — capture a screenshot and diff vs the reference.
